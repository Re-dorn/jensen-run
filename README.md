# 皮衣求生记 · Jensen, Run!

Play: https://lyreyja.com/jensen-run/

一部讽刺恶搞的网页数值模拟小游戏。2026 年 11 月，你刚刚“被辞职”，需要在接下来的 30 天里想办法活下去：逃往大洋彼岸、回乡卖牛肉汤、在 Denny’s 卡座里东山再起、投靠华盛顿，或者就这么躺着。

- 每天白天、晚上各选一次行动，管理资金、精神、声望、热度和皮衣。
- 固定日程跟随新闻时间线（财报、国会简报、感恩节……），随机事件以对话形式弹出。
- 18 个结局，支持桌面和手机竖屏，无需安装。

纯静态网页（HTML + CSS + JavaScript），无构建步骤，直接打开 `index.html` 即可本地游玩。
